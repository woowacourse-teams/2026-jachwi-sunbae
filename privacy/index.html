자취선배 개인정보 처리방침

시행일: 2026년 9월 26일

자취선배는 회원 식별과 매물 기록 기능을 제공하고 서비스를 안정적으로 운영하기 위해 필요한 정보만 처리합니다. 이 방침은 자취선배 웹 서비스와 iOS 앱에 적용됩니다.

1. 처리하는 정보

  • 닉네임, 회원 식별자, 선택적으로 설정한 비밀번호
  • 매물명, 보증금·월세·관리비, 주소, 위도·경도, 입주 가능일, 방문 일정과 선택 옵션
  • 사용자가 올린 사진, 메모, 체크리스트와 체크 결과
  • 웹 서비스의 방문 경로, 기능 이용 이벤트, 기기·브라우저 정보

현재 위치는 사용자가 위치 기능을 실행할 때 지도와 주변 시설을 표시하기 위해 사용됩니다. 사용자가 매물 위치로 선택한 주소와 좌표는 해당 회원의 매물 정보로 저장됩니다.

2. 처리 목적

  • 닉네임 로그인, 회원 식별과 접근 보호
  • 후보 매물 기록·조회·비교, 사진·메모·체크리스트 관리
  • 주소 검색, 지도 표시와 주변 시설 분석
  • 오류 확인, 보안 유지와 서비스 개선

3. 외부 서비스 이용

자취선배는 서비스 제공에 필요한 범위에서 다음 외부 서비스를 이용합니다.

  • 클라우드 호스팅 및 비공개 파일 저장소: 서비스와 사용자가 올린 사진의 저장·전송
  • NAVER Maps 및 지도 관련 제공자: 주소 검색, 좌표 변환, 지도와 주변 시설 표시
  • PostHog: 웹 서비스의 이용 경로와 기능 이벤트 분석
  • Meta Pixel: 웹 사용자가 동의한 경우에만 광고 성과 측정

iOS 앱에서는 PostHog와 Meta Pixel을 실행하지 않습니다. 자취선배는 개인정보를 판매하지 않으며, 외부 서비스에는 각 기능 제공에 필요한 범위의 정보만 전달합니다.

4. 웹 광고 성과 측정 선택

웹에서는 사용자가 동의한 경우에만 Meta Pixel을 불러오고 페이지 방문, 신규 닉네임 생성 여부와 첫 매물 등록 여부를 전송합니다. 닉네임, 비밀번호, 주소, 사진, 메모와 체크 내용은 Meta에 전송하지 않습니다. 동의하지 않아도 모든 기능을 사용할 수 있으며 서비스의 개인정보 화면에서 언제든 선택을 변경할 수 있습니다.

5. 보관과 삭제

회원 정보와 저장한 콘텐츠는 서비스 제공에 필요한 기간 동안 보관합니다. 사용자가 앱에서 매물·사진·메모를 삭제하면 해당 정보를 삭제하며, 회원 정보와 전체 기록의 삭제는 아래 문의처로 요청할 수 있습니다. 법령상 보관 의무가 있는 경우에는 필요한 기간 동안 별도로 보관할 수 있습니다.

6. 이용자의 권리

이용자는 자신의 정보에 대한 열람, 정정, 삭제와 처리 중지를 요청할 수 있습니다. 요청은 아래 이메일로 접수하며, 본인 확인에 필요한 최소한의 정보를 요청할 수 있습니다.

7. 안전성 확보 조치

자취선배는 접근 권한을 회원별로 분리하고, 선택 비밀번호를 원문이 아닌 해시 형태로 저장하며, 업로드된 사진을 비공개 저장소에 보관하는 등 개인정보 보호를 위한 조치를 적용합니다.
