# 공개 소개 명세

- 상태: 구현 기준 v1
- 관련 경로: `/intro`, `/login`, `/privacy`

## 요구사항

- `REQ-INTRO-001`: 인증하지 않은 사용자는 `/intro`에서 자취선배가 해결하는 문제와 핵심 가치를 확인합니다.
- `REQ-INTRO-002`: 소개 화면은 매물 등록, 사진·메모·3단계 체크 기록, 주변 시설 확인과 비교 PDF 흐름을 1~2분 안에 읽을 수 있는 분량으로 설명합니다.
- `REQ-INTRO-003`: 첫 화면과 마지막의 시작 CTA는 기존 닉네임 시작 화면인 `/login`으로 이동합니다.
- `REQ-INTRO-004`: Google 로그인 없이 닉네임으로 시작하고 비밀번호는 선택이라는 점을 CTA 근처에서 안내합니다.
- `REQ-INTRO-005`: 비밀번호 없이 만든 같은 닉네임은 기록을 공유한다는 정책을 마지막 CTA에서 안내합니다.
- `REQ-INTRO-006`: 첫 화면은 짧게 본 집에서 놓친 문제가 거주 중 반복될 수 있음을 제시하고, 매물의 기록과 관리로 관리비·보증금·수리비를 계약 전에 확인하도록 돕는다는 위치를 설명합니다.
- `REQ-INTRO-007`: 첫 화면의 기능 예시는 2년 총비용을 다시 보는 손실 비교와 사진·메모·발견 경로·3단계 체크·주변 시설을 모은 매물 기록 관리를 함께 보여줍니다.
- `REQ-INTRO-008`: 사용 순서 다음에는 주소 없는 빠른 등록, 현재 위치 지도 등록, 주변 시설·비교 PDF의 실제 제품 영상을 순서대로 보여주고 각 순서를 직접 선택할 수 있게 합니다.
- `REQ-INTRO-009`: 광고 측정이 설정된 환경에서는 사용 목적과 전송 범위를 먼저 알리고, 사용자가 동의한 뒤에만 Meta Pixel을 불러옵니다. `/privacy`에서 현재 선택을 확인하고 언제든 거부하거나 다시 동의할 수 있습니다.

## 정책

- `POL-INTRO-001`: `/intro`는 QR과 링크가 공통으로 가리키는 인증 전 공개 경로이며 기존 `/`, `/login`과 보호 경로의 동작은 바꾸지 않습니다.
- `POL-INTRO-002`: 소개 화면에는 앱의 하단 내비게이션을 표시하지 않고 상단과 하단의 시작 CTA에 집중합니다.
- `POL-INTRO-003`: 사용자가 저장한 사실을 정리하지만 점수·추천·자동 판단을 제공하지 않는 현재 제품 경계를 그대로 설명합니다.
- `POL-INTRO-004`: 모집 채널별 URL, UTM과 별도 신청 폼은 이번 범위에 포함하지 않습니다. 광고 귀속은 `POL-INTRO-009`의 동의 기반 Meta Pixel 이벤트만 사용합니다.
- `POL-INTRO-005`: 실제 제품과 달라질 수 있는 과거 화면 캡처 대신 현재 기능 계약과 디자인 토큰으로 구성한 반응형 예시를 사용합니다.
- `POL-INTRO-006`: 금액은 손실 가능성을 이해시키는 계산 예시로만 사용하며 실제 발생 금액이나 지원 가능 여부를 확정하지 않습니다.
- `POL-INTRO-007`: 자취선배는 임대인·공인중개사를 대체하거나 법률·지원 자격·하자 여부를 판정하지 않고, 빠진 질문을 발견해 사용자가 저장한 기록을 비교하도록 돕습니다.
- `POL-INTRO-008`: 사용 영상은 음소거·2배속으로 한 편씩 자동 재생하고 세 편이 끝나면 처음부터 반복합니다. 화면 밖에서는 재생을 멈추고 일시정지·재생 조작을 제공하며 동작 줄이기 환경에서는 정지 상태로 시작합니다.
- `POL-INTRO-009`: Meta Pixel에는 SPA `PageView`, 실제 신규 회원 생성 시 `CompleteRegistration`, 회원의 실제 첫 매물 생성 시 `FirstPropertyRecorded`만 전송합니다. 닉네임·비밀번호·주소·사진·메모·체크 내용은 전송하지 않으며, 거부·철회해도 모든 기능을 제공합니다.

## QR 배포 자산

- [공개 소개 QR PNG](../../assets/jachwisunbae-intro-qr.png)는 `https://www.jachwi-sunbae.kr/intro`를 담습니다.
- 인쇄하거나 다른 홍보물에 배치할 때 QR 가장자리의 흰색 여백을 자르거나 다른 요소로 덮지 않습니다.
- 모집 채널과 무관하게 같은 QR을 사용하며 채널 추적 파라미터를 붙이지 않습니다.

## 인수 기준

- 인증 없이 `/intro`에 직접 접근할 수 있고 API 응답을 기다리지 않고 핵심 설명을 읽을 수 있습니다.
- 390px 모바일 첫 화면에서 서비스 설명과 닉네임 시작 CTA를 확인할 수 있습니다.
- 1~2분 안에 반복되는 주거 문제, 금전 손실, 임차인 관점, 매물 기록·체크·지도·PDF 비교 흐름과 서비스 한계를 확인할 수 있습니다.
- 세 사용 영상은 사용자가 별도로 선택하지 않아도 첫 영상부터 시작하고 종료할 때 다음 영상으로 전환하며 마지막 영상 뒤 첫 영상으로 돌아갑니다.
- 영상 순서 카드를 누르면 선택한 영상의 처음으로 즉시 전환해 재생하고 현재 선택 상태를 화면과 보조 기술에 표시합니다.
- 사용자는 자동 재생을 멈추고 다시 시작할 수 있으며 동작 줄이기를 설정한 환경에서는 자동으로 움직이지 않습니다.
- 일반 모바일 폭과 데스크톱 폭에서 가로 스크롤 없이 모든 설명과 CTA를 읽고 조작할 수 있습니다.
- 키보드로 본문 바로가기, 상단 CTA, 둘러보기 앵커와 마지막 CTA를 탐색할 수 있습니다.
- 시작 CTA를 누르면 닉네임과 선택 비밀번호 입력 화면으로 이동합니다.
- Meta Pixel ID가 설정된 환경에서 결정 전에는 측정 안내를 표시하고 스크립트를 불러오지 않습니다.
- 사용자가 거부하면 Meta 스크립트를 불러오지 않고, 동의하면 현재 경로부터 SPA 페이지 방문을 중복 없이 기록합니다.
- 신규 닉네임 생성과 첫 매물 등록만 각각 한 번의 전환 이벤트가 되며 기존 닉네임 로그인과 두 번째 이후 매물 등록은 전환으로 기록하지 않습니다.
