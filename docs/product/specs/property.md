# 매물 명세

- 상태: 구현 기준 v1
- 관련 화면: `01`, `02`, `03`, `03-3`

## 요구사항

- `REQ-PROP-001`: 로그인 회원은 최대 30개의 매물을 생성·조회·수정·삭제합니다.
- `REQ-PROP-002`: 이름은 필수이고 주소·보증금·월세·발견 경로는 선택입니다.
- `REQ-PROP-003`: 주소 검색 또는 지도 선택 결과로 주소와 WGS84 좌표를 입력합니다.
- `REQ-PROP-004`: 목록은 이름·주소·금액·발견 경로·사진 수·대표 사진과 단계별(`ON_SITE`, `PRE_CONTRACT`) 진행 현황을 보여줍니다.
- `REQ-PROP-005`: 기본 정렬은 매물 ID의 내림차순입니다.
- `REQ-PROP-006`: 상세는 기본 정보, 부가정보, 사진, 메모 요약과 두 단계 체크 진행 현황을 보여줍니다.
- `REQ-PROP-007`: 비교표 받기는 현재 회원의 매물 2~5개를 고른 뒤 기본 정보·부가정보·사진·메모·두 단계 체크 기록 전체를 PDF로 내려받습니다.
- `REQ-PROP-008`: 삭제 전에 사진·메모·체크 결과가 함께 사라진다는 확인 대화상자를 표시합니다.
- `REQ-PROP-009`: 로그인 회원이 비교 화면을 열면 진입 시각과 그 시점의 보유 매물 수를 실험 이벤트로 저장합니다.
- `REQ-PROP-010`: 매물 생성 응답은 회원 생애 첫 매물인지 표시하며, 첫 매물을 삭제하고 다시 등록해도 첫 매물로 다시 표시하지 않습니다.
- `REQ-PROP-011`: 매물 등록·수정 화면은 입주 가능일, 방 옵션, 관리비 포함 공과금, 방문 일정, 확인한 곳(발견 경로)을 부가정보로 함께 입력·수정합니다.

## 정책

- `POL-PROP-001`: 이름은 trim 후 1~30자입니다.
- `POL-PROP-002`: 보증금과 월세는 원 단위 0 이상의 정수이고 미입력은 0으로 저장합니다.
- `POL-PROP-003`: 발견 경로는 trim하지 않은 원문 기준 500자 이하입니다.
- `POL-PROP-004`: 주소는 도로명·지번 구분 없는 단일 값으로 최대 255자입니다.
- `POL-PROP-005`: 위도는 -90~90, 경도는 -180~180이고 둘은 함께 있거나 함께 없어야 합니다.
- `POL-PROP-006`: 수정은 `PUT` 전체 교체입니다. 주소를 비우면 좌표도 함께 제거합니다.
- `POL-PROP-007`: 관리비는 매물 기본 정보와 별도로 부가정보 전용 필드(`maintenanceFeeAmount`)에서 관리하며, 자유 메모나 체크 항목에 중복 기록하지 않습니다.
- `POL-PROP-008`: 방 옵션은 에어컨·냉장고·세탁기·싱크대·가스레인지·전자레인지·신발장·옷장·침대·책상·TV·인덕션 중에서 여러 개를 선택합니다.
- `POL-PROP-009`: 관리비 포함 공과금은 수도세·전기세·가스비·인터넷 중에서 여러 개를 선택합니다.
- `POL-PROP-010`: PDF는 선택 순서를 유지하고 점수·추천·자동 판정을 만들지 않으며 저장된 사실만 제공합니다.
- `POL-PROP-011`: 비교 PDF는 소유자를 모두 검증하고 서로 다른 매물 2~5개만 허용합니다. 기존 CSV API는 호환용으로만 유지합니다.
- `POL-PROP-012`: 비교 화면 진입 기록 실패는 사용자의 매물 선택과 PDF 다운로드를 막지 않습니다. 소속 회원이 삭제되면 진입 기록도 함께 삭제합니다.

## 인수 기준

- 동시 생성에서도 30개 제한을 넘지 않습니다.
- 주소가 없는 기존 MVP1 매물도 목록·상세·수정에서 정상 동작합니다.
- 다른 회원의 ID로 조회·수정·삭제하면 404입니다.
- 비교 PDF를 다시 열어 선택 매물의 한글 기본 정보·메모·체크 질문·상태·항목 메모와 모든 사진이 포함됐는지 확인합니다.
- 비교 화면을 한 번 열면 진입 이벤트가 한 번 저장되고, 저장된 보유 매물 수로 2개 이상 후보를 등록한 사용자의 진입을 집계할 수 있습니다.
- 삭제 트랜잭션 성공 뒤 DB 종속 행과 객체 저장소 사진이 남지 않습니다. 객체 삭제 실패는 재시도 가능한 기록을 남깁니다.
