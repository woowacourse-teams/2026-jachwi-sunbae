# 지도 업데이트 안내

집을 등록하기 전이나 등록한 집을 살펴볼 때, 그 위치 주변의 시설을 지도에서 확인할 수 있도록 개선했습니다.

## 달라진 화면

| 화면·행동 | 달라진 점 |
| --- | --- |
| 지도 첫 진입 | 위치를 정하기 전에는 500m·1km·2km 버튼을 누를 수 없습니다. |
| 등록한 매물 선택 | 선택한 집 주변의 시설을 확인하고, 아래에서 그 집의 정보 카드 하나를 볼 수 있습니다. |
| 반경 변경 | 500m는 가까이, 1km·2km는 더 넓게 보여줍니다. 선택한 집이 있다면 그 집을 기준으로 화면도 이동합니다. |
| 지도 이동 | 지도를 옮겨도 주변 시설을 확인하는 기준 위치는 그대로입니다. |
| 현재 위치 버튼 | 내 위치로 이동하고, 내 위치 주변의 시설을 확인합니다. 위치 허용 안내도 이 버튼 옆에 표시합니다. |
| 매물 추가 | 아직 등록하지 않은 위치도 가운데 핀을 옮기면서 주변 시설을 확인할 수 있습니다. |
| 매물 마커 | 사진이 있으면 사진, 없으면 오리 로고를 검정 핀 안에 표시합니다. 가격 문구는 뺐고, 확대·축소에 따라 크기가 달라집니다. |
| 지도 축소·창 크기 변경 | 현재 지도 안에 있는 매물이 빠지지 않도록 표시 범위를 수정했습니다. |
| 아래 매물 목록 | 불러오기 전에도 손잡이를 표시합니다. 끌어올리는 중에도 내용을 보여주고, 하단 메뉴 뒤로 카드가 내려가지 않게 했습니다. |
| 지도 빈 곳 선택 | 선택한 매물을 해제하고 아래 목록을 접습니다. |

## 직접 확인하는 순서

1. 지도에 들어가 반경 버튼이 비활성화되어 있는지 확인합니다.
2. 등록된 매물 핀을 누릅니다. 해당 집의 정보 카드가 아래에 하나 표시되는지 확인합니다.
3. 병원·교통·학교·편의점 중 하나를 선택합니다.
4. 500m → 1km → 2km를 누릅니다. 같은 집을 기준으로 주변 시설과 화면 범위가 바뀌는지 확인합니다.
5. 지도를 다른 곳으로 옮긴 뒤 반경을 변경합니다. 선택한 집 쪽으로 화면이 돌아오는지 확인합니다.
6. 지도 빈 곳을 눌러 매물 선택이 해제되는지 확인합니다.
7. 매물 추가를 누르고 가운데 핀을 이동합니다. 등록 전 위치에서도 반경·시설 버튼을 사용할 수 있는지 확인합니다. 실제 등록 없이 취소해도 됩니다.
8. 아래 목록의 손잡이를 조금씩 끌어올립니다. 내용이 보이고, 목록을 스크롤해도 하단 메뉴 뒤에 카드가 보이지 않는지 확인합니다.

- 주변 시설을 제공하는 백엔드 API는 변경하지 않았습니다.
